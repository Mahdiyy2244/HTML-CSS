## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/hello-world.git
```

Enter the project:

```bash
cd hello-world
```

Then open `index.html`.

That's it.

No:

```bash
npm install
```

No:

```bash
docker compose up
```

No:

```bash
pip install everything
```

Just open the file.

**We like to keep things simple.** 😎

## 🐛 Known Issues

Currently, there are no known bugs.

However, this is suspicious.

We recommend checking again later.

Potential future issues include:

* World refusing to say hello back
* Hello becoming too friendly
* Browser judging your code
* Developer accidentally adding React

The last one is considered a **critical security vulnerability**.
